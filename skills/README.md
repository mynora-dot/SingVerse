# NoraMusic 开发技能

本目录面向 NoraMusic 的 Flutter/Dart 客户端与 Android 设备验证。原型位于 `prototype/android-prototype/`；生产客户端使用 Flutter。按任务阅读对应目录的 `SKILL.md`，技能目录中的 `references/`、`examples/` 和 `scripts/` 是其配套资源。

| 任务 | 技能 |
| --- | --- |
| UI、适配、动效与交互审查 | `ui-ux-pro-max` |
| Dart 代码 | `dart-use-pattern-matching` |
| 测试与审查 | `flutter-add-widget-test`、`flutter-code-review` |
| Android 真机/模拟器调试 | `android-emulator-browser` |

UI/UX 任务统一使用 `ui-ux-pro-max`。针对本项目必须明确使用 Flutter 技术栈，并遵守仓库现有的 Riverpod、业务层/服务层边界、主题 token 和组件体系；该技能的网页、CSS、Tailwind 或其他技术栈建议不能直接替代 Flutter 实现规则。

仓库根目录的 `skills/` 是项目资料目录；具体能否被 Codex 自动发现取决于运行环境的技能发现配置，必要时直接指定相应 `SKILL.md`。

| Web/UI cleanup and visual quality | `unslop` |
| Product and graphic design workflows | `huashu-design` |
