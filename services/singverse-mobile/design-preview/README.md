# 手机播放器双方案设计稿

独立的 HTML 交互预览，用于确定 Flutter 手机播放器的视觉方向。A「沉浸深色」突出 MV 与歌词，B「清爽浅色」采用浅色控制区与独立录音入口。两版均包含竖屏 MV、纯音频歌词和横屏舞台；本阶段未替换正式 Flutter 页面。

## 打开预览

直接使用浏览器打开本目录 `index.html`，无需安装依赖或构建。页面仅使用仓库中的相对资源，不依赖 CDN、网络字体或 NAS。

也可从仓库根目录启动仅限本机的静态服务：

```sh
python3 -m http.server 18768 --bind 127.0.0.1 --directory .
```

访问 <http://127.0.0.1:18768/services/singverse-mobile/design-preview/>。服务根目录需保留仓库相对结构，因为示意图片与 Logo 复用已有素材。

- 桌面宽屏同时对比两版；竖屏方案左右排列，横屏方案上下排列。窄屏用「A / B」按钮切换。
- 顶部切换 MV、音频歌词、横屏舞台，并可检查 1.8 倍文字与至少 56px 的长辈触控区域；普通模式至少 48px。
- 可演示播放/暂停、进度拖动、点歌词定位、原唱/伴奏、收藏、调音、选段和单曲循环。录音为三秒倒数、录音状态及结束结果的本地模拟。
- 弹层支持 Escape 关闭、Tab 焦点循环和关闭后返回触发按钮。横屏提供明确的收起/显示控制按钮；录音期间保持可结束的入口。
- 所有状态仅保存在本页内存，刷新恢复。没有媒体播放、声音采集、文件生成、浏览器持久存储、NAS API 或原生平台调用。

## 设备尺寸评审

使用查询参数 `?device=1&theme=dark&scene=mv` 隐藏评审外框，让播放器直接铺满浏览器视口，方便使用开发者工具核对 320×568、390×844、844×390。

| 参数 | 可选值 |
| --- | --- |
| `device` | `1`：仅显示播放器 |
| `theme` | `dark` / `light`：窄屏或设备视图下的方案 |
| `scene` | `mv` / `audio` / `landscape` |
| `font` | `1.8`：大字检查；省略为标准字号 |
| `senior` | `1`：触控目标至少 56px；省略为至少 48px |

短屏和大字下允许内容纵向滚动，保持控制可达；横屏控制区内部可滚动。减少动画设置遵循 `prefers-reduced-motion`。此开关仅用于设计约束检查，不代表完整的 Flutter 长辈模式改版。

## 内容与素材

- 「把晚风唱给你 / 林间回声 / 晚风来信」均为虚构示例；歌词为本次原创，不代表真实 NAS 曲库。
- 海岸 MV 静帧与封面复用 `../../singverse-tv/app/src/debug/assets/home-hero.png`，来源及生成记录见 TV 工程的 `design-preview/README.md`。
- Logo 与 favicon 复用根目录 `assets/branding/icons/`；图标为本地统一线性 SVG。
- 未修改正式播放器、API、业务状态、Android 桥接、数据库或构建流程。HTML 中的字幕、音轨、调音、收藏与录音状态仅用于交互评审。

浏览器检查只验证设计稿。它不能证明 Flutter 布局、真机字体、解码、麦克风或音画同步已经通过验收。
