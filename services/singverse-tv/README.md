# SingVerse Android TV

包名 `com.mynora.singverse.tv`。Kotlin / Jetpack Compose TV，采用 Apple TV 启发的中性黑灰设计、轻量胶囊导航与白色焦点反馈。已接入 NAS 地址检测、管理员批准的设备授权、正式分类/歌手署名浏览、歌曲查询、本地/WebDAV 原始媒体直放、聚会队列、扫码邀请和本机主持操作。

版本沿用 AGP 8.9.2、Gradle 8.11.1、Kotlin 2.1.20、Compose BOM 2025.04.01、TV Material 1.0.0；新增 Media3 1.5.1 和 ZXing Core 3.5.3。compile/target SDK 35、minSdk 23；构建 JDK 21，字节码目标 17。

```sh
# 根目录：单元测试、编译 debug APK 并执行 lint
make tv-build
# 或在本目录使用仓库 Wrapper
./gradlew testDebugUnitTest assembleDebug lintDebug
./gradlew installDebug
```

设置 ANDROID_HOME 或本地 local.properties，安装 SDK 35 / Build Tools 35.0.0。APK 位于 `app/build/outputs/apk/debug/`，不提交生成产物。

## 开场

1. 启动 Java/Nginx，先在 NAS 管理页扫描自备曲库。
2. TV 输入电视和手机可达的 NAS 根地址，例如 `http://<NAS内网地址>:18080`，不使用 localhost 或容器 IP。HTTP 只允许本机/私有网络解析地址；HTTPS 使用系统证书验证。
3. 在管理页“系统设置 → 电视设备”核对名称和电视显示的六位短码，批准后电视自动领取凭据。凭据通过 Android Keystore 加密保存，应用不允许备份。
4. TV 找歌并加入待唱，在首页/已点确认开始；本场邀请二维码供微信扫描，亲友填写昵称后加入。主持授权或撤销参与设备在 TV 设置页完成。

方向键导航、确认键操作、返回键先关闭弹层/控制层，再返回首页；详情返回恢复歌曲焦点。演唱页确认键打开控制，支持暂停、继续、重唱、±10 秒与本机停止。切歌后需要在 TV 确认下一首，不自动开唱；应用后台暂停，进程重建须重新确认开唱。

## 边界

仅直放，不进行重封装、转码、缓存兼容副本或 HLS。文件不能解码时显示真实失败，可重唱/换歌；未知音轨语义时不显示原唱/伴奏开关。无评分、录音或消人声。正式分类复用 NAS 已应用结果，歌手按精确署名分组；支持有效歌名、歌手、专辑的拼音全拼/首字母和已解析歌曲编号精确检索；多音字采用词典首读音，不自动归并歌手或作品。服务端共享只读索引在 30 秒内刷新，首页刷新使索引失效；超大曲库仍需按实际规模验收。

设备与参与者使用独立 Bearer 身份，不能访问管理接口；WebDAV 凭据保留在 Java。主服务持久化业务状态，电视只执行命令与上报真实播放。断线可本地暂停/停止，重新同步不自动重发点歌。

完整设计与转码后续安排见 [TV 端开发设计](../../docs/tv-development-design.md)。构建、模拟器和 HTTP 测试不代表微信、真实电视/音响、NAS 或 API 21 兼容性验收。

## TV 视觉与页面组织

`TvComponents.kt` 统一主题、按钮、封面卡片、空态与确认后编辑输入；`TvScreens.kt` 组织页面和弹窗。底色为 #08090B、表面 #191B20、主文字 #F5F5F7、次文字 #A1A1AA，蓝色仅用于状态与进度。封面焦点以约 160ms 缩放到 1.04；使用系统字体和显式行高，不依赖实时模糊或新系统特效。

首页展示本场演唱/下一首与实际曲库横向列表，顶部“手机加入”打开独立邀请面板；已点通过整行焦点进入操作面板，设置采用分组与详情区域。全屏播放控制分为主要操作、时间进度与次要操作。无封面使用中性渐变和绘制的音乐图标，无空库示例数据。长标题在卡片截断、详情最多两行；弹窗默认聚焦取消/返回。

当前 NAS 授权、队列、播放器生命周期与 API 保持原有行为。截图与本轮设备检查见验证记录；Android TV 模拟器不替代真实电视/音响验收。

## 实际后端数据绑定

连接授权后首页调用 `/api/v1/tv/home`，曲库横向列表与全库数量独立于找歌结果；进入首页和点击“刷新曲库”重新读取，停留首页时约每 30 秒同步一次。找歌与歌手分别持有搜索词、页码和总数，切页不互相覆盖。分类进入时刷新正式词表，停留时约每 30 秒同步；队列及本场参与者仍走已有聚会快照接口。

打开歌曲卡片时通过 `/api/v1/tv/library/songs/{id}` 获取当前详情，显示真实可用的专辑、发行日期和时长。更新元数据或封面后依展示 revision 重新加载封面；歌曲已移除时提示真实 404。换 NAS 清除旧列表与筛选，迟到详情响应不能重新打开已离开的页面。接口必须由新版 Java 提供；开发联调地址不会硬编码进产品，电视仍输入自己 NAS 的地址并经管理员授权。

本地联调可访问宿主机 `http://127.0.0.1:18080`；Android 模拟器连接同一服务填写 `http://10.0.2.2:18080`。这只是模拟器访问宿主机的测试地址，真实电视与手机应改用手机可达的 NAS 内网地址。

## 音轨、歌词与声音

演唱控制或「设置 → 播放设置」提供音轨、歌词字幕、声音输出与同步面板。音轨仅列 Media3 判断设备可支持的轨道；双声道 PCM 可选择左、右、混合单声道。原唱/伴奏通过用户听辨后记录当前轨道与声道，按 NAS 曲目及媒体/元数据 revision 保存到本机；源文件变化后旧映射失效，不猜测第二轨的含义。

Java 提供同目录、同文件名主体的 `.lrc` / `.srt` / `.vtt`（小写扩展名），单文件上限 128 KiB；支持严格 UTF-8、带 BOM 的 UTF-16。仅从已配置本地/WebDAV 来源读取，拒绝越界路径/重定向，源凭据不传电视。TV 解析普通/增强 LRC、SRT、VTT，按真实时间戳显示；增强 LRC 按已有词时间戳高亮。内嵌字幕交给 Media3，可选择识别出的字幕轨或关闭。文本可读不代表编码字幕可解码。

升降调范围 ±6 半音、速度保持 1 倍；应用音量 0–100%。输出设备是 Android 优先路由请求，实际 HDMI/蓝牙/音响路由由系统协商。外置歌词偏移 ±5 秒；PCM 音频可延后 0–500ms，默认 0；内嵌字幕沿用原时间轴。音量和偏移保存在本机，音调每首恢复原调。音频处理发生在电视 PCM 播放链，不生成媒体副本，也不改变 NAS 文件。真实音画同步与音响效果必须真机听辨。

断线后仍可本机暂停/停止；有未确认请求时阻止新点歌，用户可用原 requestId 重试或放弃本次重试。重连先读取快照，明确的 4xx 拒绝会解除请求占用；不会自动重发点歌或跳歌。播放进度每 200ms 取播放器实际位置，上报约每 5 秒。

## 局域网发现

连接页点击「查找局域网 NAS」，通过 Android NSD 发现 `_singverse._tcp.`，15 秒结束，点击候选只填入地址，仍需身份检查和管理员授权。Java 原生部署可配置 `SINGVERSE_TV_DISCOVERY_ADDRESS=<本机内网IP>`、`SINGVERSE_TV_DISCOVERY_PORT=<实际HTTP入口端口>`；默认关闭，不自动暴露服务。当前广告指向 HTTP 内网入口；HTTPS 入口手动填写。

桥接 Docker 的组播和容器地址通常不能供电视使用，请在 NAS 宿主机发布同一服务类型，例如 Avahi 的 `_singverse._tcp` 服务配置（端口为实际 Nginx 入口）；macOS 可用 `dns-sd -R "SingVerse NAS" _singverse._tcp local. <端口>`。仅在入口已绑定可达 LAN 地址后发布。模拟器宿主机隔离网和访客 Wi-Fi 不保证组播互通，手填地址始终可用。

## 签名与应用内更新

`make tv-release` 要求环境提供 `SINGVERSE_TV_KEYSTORE`、`SINGVERSE_TV_STORE_PASSWORD`、`SINGVERSE_TV_KEY_ALIAS`、`SINGVERSE_TV_KEY_PASSWORD`；密钥由发行方保管，不入库。版本用 `ORG_GRADLE_PROJECT_singverseVersionCode` / `ORG_GRADLE_PROJECT_singverseVersionName` 或 Wrapper 的对应 `-P` 参数递增。任务生成 `app/build/tv-release/singverse-tv.apk` 与 `release.json`，执行 release lint。未配置密钥时明确失败；普通 debug 构建不需要正式密钥。

将两个文件一起复制到 NAS 的专用发布目录，设置 Java 的 `SINGVERSE_TV_RELEASE_DIRECTORY`。Docker 中目录必须是容器内路径，例如持久卷 `/data/tv-releases`，宿主机可用 `docker compose -f compose.app.yaml cp <文件> singverse-java-backend:/data/tv-releases/`，自行创建目录后再发布；不要放到媒体原件目录。发布期间不应覆盖正在下载的文件，建议停用发布目录配置后成对替换再启用。

「设置 → 应用更新」检查实际 manifest，下载后核对大小、SHA-256、包名、递增 versionCode 及与当前应用完全一致的签名，再经 Android 安装确认。Android 8+ 首次需要在系统页面允许此应用安装并返回重试；不静默安装。调试签名与正式签名不同，不能将正式包作为 debug 包的应用内升级；首次正式安装由发行方安排。`release.json` 只声明 versionCode/versionName，服务端实际计算包大小和 SHA-256，单包最多 256 MiB。未发布时显示真实空态。

快照另含 stateRevision（包含播放事件的持久版本），TV 不接受同会话较低版本、换会话或换NAS后的迟到状态；队列命令仍提交 revision。

封面请求限制响应2MB，解码最长边约512px，16MiB有界内存缓存按NAS/封面路径/revision分开；换NAS清空缓存，减少翻页和返回时的重复读取。


### 分类封面卡片

分类改为三列16:9图片卡片，封面从Java的正式标签投影coverPath/coverVersion读取，设备Bearer鉴权，按内容版本更新有界缓存。聚焦白色边框与轻微放大，已选为独立标记；卡片保留真实歌曲数量、长名称截断和加载失败提示。未上传时显示低饱和渐变与分类名称，不填示例图片。管理端「歌曲分类 → 分类词表」上传/更换/移除后，重新进入TV分类即可刷新，停留时约30秒同步。分类逻辑仍同维OR/跨维AND。

分类封面大卡片保留最长边1280px解码以适配4K，歌曲缩略图仍为约512px，两者共用16MiB有界缓存；替换图片时取消旧请求不会覆盖新版本。

## 自动歌手库

扫描后按歌曲有效署名自动生成，不再人工建档/关联。管理端歌手详情可打开歌曲编辑器订正歌手，NAS 覆盖值优先于文件标签并在重新扫描后保留；恢复扫描值需确认。首次后台从网易云/QQ 核对歌曲并取真实歌手头像，失败有限重试，无可靠匹配保留占位。上传图片优先，移除后暂停自动补图。TV 自动展示同步结果和受权图片，保留返回焦点。迁移 `202610290008`，新增接口、来源与状态见 OpenAPI 和 [自动歌手库说明](../../docs/artist-library.md)。

歌手详情横幅优先显示独立背景图；只有头像时，TV 在内存中生成低分辨率柔化背景并压暗，不回写 NAS；没有任何图片时保留渐变。生成背景带文字标识，头像和返回按钮的布局及焦点不变。

## 歌单分类

顶部「歌单」展示 NAS 管理端保存的共享歌单，支持搜索、分页、真实歌曲封面/缺图占位、详情和按保存顺序浏览歌曲，并沿用歌曲详情点歌流程。歌单浏览与聚会队列独立，不自动入队整张歌单，不重建播放器；返回恢复歌单卡片焦点。管理端编辑内容随曲库轮询同步，已删除歌单返回列表。空歌单/已移除歌曲如实展示，详见根 `docs/playlists.md`。

## 兼容播放

TV 已接入能力协商、Media3 HLS、画质切换和失败兼容重试。播放位置/歌词使用原媒体时间轴；新的原唱/伴奏标记使用源流 ID。当前软件解码/滤镜加硬件编码的服务端边界和真机待验收项见[转码说明](../../docs/transcoding.md)。

### 全曲库原唱/伴奏

演唱设置中的音轨标记现在写入 Java 全曲库元数据，使用源 stream ID 和修订号；订正不改变当前播放，点击“使用原唱/伴奏”时重新协商。单音轨生成的伴奏与原视频通过同一个 Media3 播放器合并，按 HLS 原时间轴偏移对齐，支持继续拖动。单音轨仍可返回原唱；失败或取消的分离任务不会显示为可用伴奏。大屏按钮沿用遥控焦点组件，遥控真机、HDMI/蓝牙音画同步仍须验收。

单轨左右声道的既有标记继续保存在本机并按素材版本隔离；全曲库纠正仅保存两条源音轨角色，立体声不会被自动当作双音轨。
