# 歌手库模块

列表从歌曲有效署名自动汇总，封面优先展示头像。常驻男歌手、女歌手、组合与待分类筛选，缺封面/待确认、搜索和歌曲数量条件提交 Go，在分页与计数前筛选。

本页选择和跨页保留明确区分；最多 1000 位。批量封面面板选择已选范围或全部筛选快照，按真实平台启用情况提交，失败保留表单与幂等标识。持久化批次离页继续，返回或任务深链接恢复实际结果；组件卸载停止轮询并忽略迟到结果。批量类型标注携带每位歌手版本并由 Go 原子确认，不推断性别。

图片平台支持自动匹配、网易云、QQ、酷狗、酷我、汽水和 TheAudioDB；网易云/QQ/酷狗沿用歌曲信息的平台启用状态，酷我、汽水直接读取公开歌手目录。选择平台后按所选标识提交，批次与历史结果使用统一中文平台名称；同名歌手核对不足仍需确认候选。

详情保留头像/背景上传及删除、独立图片版本、候选明确确认、来源说明、关联歌曲分页、SingleSongScrapeDialog 订正和恢复扫描值。Cookie/CSRF、上传取消、并发版本保护与歌曲归属刷新继续生效，不提供人物建档或假对话能力。

接口见 OpenAPI，业务及平台限制见 [歌手库说明](../../../../../../docs/artist-library.md)。
