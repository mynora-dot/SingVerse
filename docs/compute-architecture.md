# SingVerse Compute 工程架构

## 边界与职责

计算服务是内部执行层，负责 FFmpeg/ffprobe、实时 HLS、离线兼容版本、音轨分析和可选伴奏分离。Go 负责管理员及设备授权、任务编排、素材指纹、结果校验和唯一业务写入；客户端仅调用 Go。compute 不写业务数据库、不管理聚会队列，不引入 Redis 或多节点调度。具体播放和任务协议见[转码说明](transcoding.md)。

## 包与依赖方向

| 包 | 负责 | 禁止 |
|---|---|---|
| core | 不可变配置、日志规范、错误语义 | FastAPI 路由、业务库、FFmpeg 调用 |
| domain | 媒体值对象 | HTTP DTO、外部工具、全局配置 |
| application | 用例、端口协议、资源并发和释放 | HTTP 框架、业务数据库 |
| infrastructure | 凭据文件、授权回源、工具和模型适配 | 业务 SQL、页面规则 |
| api | DTO、路由、注入、边界中间件、错误映射 | 业务持久化 |
| bootstrap | 组装配置、适配器、服务和 FastAPI | 具体任务逻辑 |

`__main__` 负责 CLI 启动，`app.py` 保留 ASGI 导入。新能力按实际需求新增用例及适配器，再注册路由、认证和能力声明；不存在实际适配器时不声明能力。

## 授权回源与标签读取

1. Go 核对歌曲权限和素材身份，创建短期任务引用，发送 `reference`、`callbackOrigin`、文件名及大小，不发送本机路径或 WebDAV 凭据。
2. API 在解析 JSON 前检查内部 Bearer 及请求体大小；标签使用 `/internal/v1/media/remote-tags`，已移除路径式 `/internal/v1/media/tags`。
3. 每个应用实例拥有独立的单名额标签并发门。同步路由在框架线程池执行，`finally` 释放名额。
4. `RangeFile` 仅访问 Go 固定的内部回源入口，校验 Range、大小及稳定性，不跟随重定向。普通读取最多 16MiB、16 次请求和 60 秒；深度读取最多 128MiB、64 次请求和 180 秒，缓存按 1MiB 块共享。
5. 标签解析和受限 FFprobe/FFmpeg 通过随机 loopback 路由读取素材。代理写客户端 socket 时不持有文件缓存锁；服务关闭轮询为 20ms，避免每项任务附加约半秒等待。
6. Go 校验字段范围和当前指纹后保存快照；失败保留文件名回退，原媒体不改写。远程标签仍复用 `ffprobe.normalize`，不保留已废弃的本地路径任务分支。

## 资源与生命周期

Settings 在应用创建时冻结。凭据文件由计算服务创建并保留，Go 只读共享或加密保存连接凭据，不共享管理员主密钥。健康只说明 HTTP 进程存活；能力、模型试跑和素材硬件试跑分别核实，空能力列表不能执行媒体任务。

能力探测在线程池执行。单次模型状态查询共享设备/策略快照；RKNN 摘要按文件身份、大小和纳秒时间戳缓存，更换文件或试跑时重新校验。HLS 导出哈希、目录统计在调度锁外执行，导出引用在完成或失败前阻止回收。已确认释放的离线执行日志保留 7 天后清理；未释放执行仍按任务恢复协议处理。

媒体子进程受并发、线程、时间、输出和观测内存预算约束。取消、失败和过期任务清理临时产物，活动读者及租约受保护。Go 接收产物设置 30 秒正文空闲超时，取消可关闭在途下载；下载不占用音频服务全局锁，失败清理临时文件及容量预留。

## 部署与连接

Docker 计算镜像使用 Python 3.12 和 `requirements.lock`，包含 FFmpeg；Go 不执行 Python/FFmpeg。原始曲库仅供 Go 读取，计算节点无需同路径媒体挂载。内部凭据与执行缓存独立保存；跨主机先落实认证、TLS/受限网络及双向回源，不能直接暴露公网。具体变量和独立部署方式见[节点 README](../services/singverse-compute/README.md)。

Go `compute` 包提供 AUTO/MANUAL/DISABLED 配置、加密凭据、局域网配对和实际连接检查。AUTO 未配置地址时关闭探测，可选节点不加入主服务健康依赖。任务固定连接及素材身份，切换节点不向新节点重复发送旧任务；路径映射只保留已有配置读取，新任务不使用。

## 可观察性与验证

JSON 请求日志记录请求 ID、方法、路径、状态和耗时，不记录 Authorization、任务正文或来源凭据。业务错误统一映射 Problem Details；诊断不回显媒体路径或密钥。

单元测试覆盖标签预算、哈希缓存失效、导出/回收竞态、取消和日志释放；随机回环 HTTP 测试覆盖认证、回源、请求边界和 OpenAPI。`make backend-check` 验证真实 Go/Python/FFmpeg 及节点离线、上线和退出，使用隔离数据库和自制媒体。模型或硬件所需环境缺失时单独记录，测试通过不代替 NAS、微信或硬件真机验收。
