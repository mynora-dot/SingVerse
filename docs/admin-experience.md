# 家庭音乐中心：网页管理端

网页为手机、TV 和亲友点歌准备内容，是普通用户「管理歌曲、整理内容、准备伴奏、连接设备、配置服务」的日常入口。真实点歌与演唱发生在手机、TV 与亲友 H5；网页中的试听与播放用于核对媒体、音轨、伴奏和兼容性。产品不把浏览器变成新的 K 歌客户端；助手沿用现有形象与展示能力，不提供尚未实现的对话或工具调用。

## 信息架构与导航

主导航五项用普通用户词汇：**首页 · 曲库 · 加歌 · 整理 · 客厅**；顶栏右侧为任务中心（活跃数徽章）与设置两个 utility 入口。手机导航面板列出全部入口。二级导航只展示当前工作区，技术细节折叠进「高级 / 技术信息」。**全部页面路径保持兼容**，名称与组织改变；旧深链按下方规则解析。

|---|---|

| 曲库 `#/library/songs` | 歌曲 `#/library/songs` · 歌手 `#/library/artists` · 歌单 `#/library/playlists` · 分类标签 `#/library/classification` |

### 统一歌曲页与透镜

`#/library/songs` 是统一歌曲工作台，按 query 判定透镜：

| URL 形态 | 透镜 |
|---|---|
| 无 query | 歌曲（封面浏览 / 密集列表） |
| `lens=songs` / `lens=formal` | 显式指定 |
| 仅 `search/sourceId/page`（无 lens、无文件专属参数） | 重定向补 `lens=formal`，保留旧正式列表深链语义 |
| 含 `q/status/tagIds/unclassified/size/detailSongId/reviewSongId` | 歌曲透镜（消费首页与后端 TRANSCODE 深链） |
| `#/library/songs/files?<任意>` | 重定向补 `lens=songs`，保留全部 query 与 hash |

歌曲透镜写入恒带 `lens=songs`，资料透镜恒带 `lens=formal`；切换保留 `search/sourceId/page`，切向资料丢弃文件专属参数。后端 `relatedPath` 的 TRANSCODE 深链 `?detailSongId=` 与人工核对 `?reviewSongId&returnBatch` 均由歌曲透镜消费。

## 视觉与组件

当前视觉方向为「家庭音乐资料室」：沉静、清楚、有收藏感。保留多端共用的 SingVerse 标识，以中性表面和单一品牌蓝组织操作；真实歌曲封面与歌手照片承担色彩重点。首页保留「曲库概览」的无障碍标题语义，取消独立可见标题与副说明，将曲库、加歌和刷新合并为紧凑入口条，保留原有内容顺序。二级页面采用用户选定的 C「浏览优先」：小型内容名称与主要操作共行，筛选直接贴近内容，减少独立大卡片与重复工具层。登录保留分栏和两阶段验证，移除英文装饰眉题、声波与大型唱片。缺失封面使用中性唱片占位，不按歌曲 ID 随机配色。

| 设计项 | 浅色 | 深色 |
|---|---|---|
| 页面 / 面板 | `#fafafa` / `#ffffff` | `#141415` / `#19191b` |
| 主文字 / 次文字 / 辅助文字 | `#171717` / `#525252` / `#666666` | `#ededed` / `#b0b0b5` / `#9898a0` |
| 主强调 / 强调文字 | `#2563eb` / 白色 | `#60a5fa` / `#111827` |
| 尺寸 | 4px 间距网格，正文 14px、辅助 12–13px；独立页面标题 28px，二级内容栏标题18px | 共用同一套布局与字号 |
| 控件 / 面板 / 弹层圆角 | 8 / 12 / 16px | 同浅色 |
| 顶栏 / 内容宽度 / 页边距 | 64px / 最大 1480px / 桌面 32px、手机 16px | 同浅色 |

共享组件 `PageShell / PageHeader / StatusBadge / EmptyState / FilterBar / BatchBar / StatBlock / ThemeSwitcher` 与既有 `SongCover / TaskGuide`、危险确认继续复用原 props、slots 和事件。旧第二强调色令牌保留为品牌蓝别名，避免已有模块产生不同色彩体系。语义色仅表示状态。Element Plus 配色阶梯以当前面板色混合，避免深色控件混入白底。字重使用 400/500/600，数字采用等宽数字；不加载外部字体或新组件依赖。播放器与封面编辑预览保持适合媒体的深色舞台，真实封面、图片与助手宠物保留自身内容。

表格在容器内横滚；歌曲表桌面保留固定列，手机取消固定列以避免互相遮挡。表头、悬停、选中和键盘焦点分别表达。移动布局调整表格容器、列数、表单及审核布局，普通控件 40px，手机点击区域至少 44px；导航保留焦点限制、Escape 关闭和焦点恢复。动效仅提供交互反馈，统一缓动并尊重减少动态效果偏好。

### 主题系统

主题仅有 `light`（浅色，默认）与 `dark`（深色），`ThemeId` 为对应联合类型。浅色令牌在 `tokens.css`，深色覆盖在 `themes.css`。切换器保留桌面下拉与移动导航两种呈现，仅展示两种外观；不跟随系统，不同步账号，不写业务库。

`main.ts` 挂载前调用 `initTheme()`，读取 `localStorage['singverse.admin.theme']` 并同步 dataset 与响应式状态。旧 `indigo/pine/vermilion/celadon` 迁移为 `light`，`midnight/graphite` 迁移为 `dark` 并写回新值；缺失或非法值默认浅色，隐私模式下读写失败均降级而不阻止显示。亲友 H5 不加载管理端主题。

本轮设计审查参考仓库 [Unslop 技能](../skills/unslop/SKILL.md)，作者 Damir Sokolovsky（@heydamir），CC BY 4.0；按间距、配色、图标、文案、字体、布局、细节、视觉与动效逐项整理。下方历次记录保留当时的主题和验证事实，当前行为以上述说明与源码为准。

### 二级页面内容区（2026-11-12）

按 [huashu-design](../skills/huashu-design/SKILL.md) 完成三方向原型后，用户选择 C「浏览优先」。统一覆盖全部20个二级菜单与歌曲高级资料、文件名自定义规则、AI深层设置、音频处理记录等子视图。

- **集合页**：内容名称／数量与添加共行；说明用有名称的图标入口按需展开。搜索、来源和状态直接贴着内容，范围、统计与列表工具同组。歌曲整理／高级资料放进更多；批量动作仍在选择后出现，歌曲本页与歌手跨页范围不混用。
- **流程页**：范围和启动动作同组，暂停／继续／终止贴对应批次，审核筛选贴结果；去掉介绍侧栏和多层外框，保留任务状态及按需说明。
- **设置页**：账户和安全按行分隔；计算连接、模型、缓存策略和AI配置按各自区域组织。保存、重载和冲突仍归原表单，不增加全页统一保存。
- **客厅与任务**：电视画面保留媒体预览；设备授权、播放记录、缺歌与任务列表用轻量分隔线组织。刷新贴当前内容，表格内部横滚，详情保留原返回筛选与轮询。

`PageHeader` 的原props、actions／description槽保持，新增可选meta槽显示数量。手机保留搜索和主动作，来源／分类等筛选及本页统计按需展开，结果范围与视图／选择／刷新工具同组；说明与更多菜单关闭后恢复键盘焦点。标题为18px语义h1，不恢复旧的大标题／副说明区。主题、API、hash路径、选择／草稿保护、播放器与后台轮询规则保持原行为。

| 状态 | 呈现与下一步 |
|---|---|
| 尚未准备 | 空曲库、缺节点、无 AI 分别说明原因并提供对应入口；不阻止不依赖该能力的功能 |

## 接口与验证边界

歌曲搜索沿用 `GET /api/v1/media-songs?search=`：在 Go 使用与展示一致的有效信息投影（路径 + 有效歌名 + 有效歌手，stale=false 的 song_metadata 覆盖 result_json），和原有 SQL 筛选处于同一事务，先过滤计数再返回页；排序 `scannedAt DESC, id ASC`，特殊字符按字面匹配，流式仅保留当前页。旧 `q` 的文件路径含义不变，作为高级「仅文件路径」筛选。

首页新增只读聚合端点 `GET /api/v1/admin/overview`（operationId `getAdminOverview`，sessionCookie，`no-store`）：注册在管理端 Cookie/CSRF 边界之后，TV/party Bearer → 401 problem+json。每块独立采集（~5s 超时），失败置 null 并写入 `errors` map；数据库全挂 → 503 problem+json。section 含 `library / sources / review / tv / tasks / recentSongs / playback30d / cache / readiness / playlists`，`recentSongs` 与 `/media-songs` 投影完全一致，`tasks` 与 `/background-tasks` 一致（未知进度 null）。聚合优先复用各域已导出方法，仅缺口处加薄封装，不复制 SQL，无迁移。首页 mount/手动刷新调 1 次聚合；10s 任务轮询仍只打 `/background-tasks?view=ACTIVE&size=3`，全局徽章 30s size=1，聚合不进轮询。OpenAPI 与 SQLite/MySQL 业务测试同步覆盖；不动冻结迁移基线。
