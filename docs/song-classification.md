# 歌曲 AI 分类

管理后台“曲库管理 → 歌曲分类”，或歌曲列表选择歌曲后“AI 分类已选”。分类只关联现有歌曲 ID，不合并同名文件，不修改原媒体及刮削结果。手机与电视页面尚未接入；当前 API 仍要求管理员会话，不新增公开读取权限。

## 管理页面使用

页面按“开始分类 / 分类记录 / 分类词表”分区。开始分类先选已选歌曲或整个曲库，再选择语种、发行年代、风格、情绪、场景；歌曲列表批量选中后的 `songIds` 深链接保持兼容。无预选歌曲时直接打开本页选歌弹窗，不跳到全部歌曲页；弹窗复用歌曲检索接口，支持搜索、每页 20 首、选择本页和跨页保留，确认后回填歌曲 ID 与数量，取消不覆盖原选择。选择整个曲库须显式操作，仍受每批 5000 首限制。

默认先生成建议，逐首查看并勾选后保存。自动保存仅在“更多保存选项”内显式开启，并继续要求逐项选择允许自动保存的分类内容。下一步先读取真实输入预览，确认后才创建任务。

分类记录集中查看进度、暂停/继续/终止、结果筛选和人工整理。结果卡片区分待确认、已保存、未成功，状态筛选及明细分页由服务端执行；切换时清除旧列表并保护迟到响应。确认弹窗对比当前分类与 AI 建议，锁定及人工确认覆盖规则保留。手动整理先勾选修改项才展开标签；历史及撤回保留在折叠区。词表独立提供搜索、分类内容筛选、歌曲数量跳转及编辑。模型摘要位于开始页辅助区，配置仍只在 AI 设置。

## 配置与使用

先到“系统设置 → AI 设置 → 模型服务”保存服务，再在“功能配置 → 歌曲分类”绑定模型、启用分类并设置请求间隔。分类业务页仅展示绑定状态和配置跳转，任务范围、维度、单次自动应用、词表、审核和人工整理仍在此页。

支持 Responses、Chat Completions、Anthropic Messages、Gemini GenerateContent，显式选择 JSON Schema 或 JSON 对象模式（Anthropic 原生使用 Schema）；无论选择哪种模式，都执行相同的分类结果校验，不自动降级。模型服务的“分类结构化输出验证”发送空歌曲测试输入，不评估分类质量。远程模型要求 HTTPS，本机/局域网可使用 HTTP；密钥加密与迁移规则见 [AI 设置](ai-settings.md)。

正式分类前预览前 20 首输入和总数，最多每批 5000 首。只发送歌名、歌手、专辑、已确认发行日期、文件名解析语种/版本/质量标签、歌曲 ID 和目标词表，不发送文件路径、媒体或凭据。使用已有本地元数据不代表模型在本地运行；远程模型会接收这些歌曲信息。本阶段不联网搜索、不分析音频。

维度固定为语种、发行年代、风格、情绪、场景、自定义。词表可增补、改名、维护别名或停用（最多 1000 标签）；每个维度最多 8 标签。已有明确语种优先沿用；发行年代只从已有有效年份归组，不猜作品创作/首次发行年代。风格、情绪、场景为 AI 推断。无依据可为空；新标签仅作为文字建议，不自动创建。自定义标签只人工维护。

## 应用与保护

自动应用默认关闭，创建任务时逐维度开启；模型自报分数和刮削相似度都不作为分类正确率。自动结果标为 AI 生成；已有人工确认或锁定维度不能自动覆盖。审核确认后标记人工确认，锁定维度必须先通过人工整理解锁。审核只应用选中且非空建议，其余保留；该次审核结束后条目标为已应用，不表示全部建议均已写入。

人工整理支持单首/当前页选中的多首歌曲，只替换选中维度。明确保存空标签会清除该维度，界面要求确认。每首单独事务并报告失败；批量操作不宣称跨歌曲原子性。分类状态、标签关系及变更历史同时提交；提交标识提供幂等重试。人工或 AI 应用均可在历史中查看前后值；只有仍处于该次修改后的版本才能撤回，后续人工修改或锁定变化会阻止撤回。无实际变化不生成历史。

任务冻结模型配置（包括加密凭据）、词表、歌曲输入和自动应用维度。生成后歌曲信息、文件指纹、分类版本或标签版本变化时阻止自动应用并显示审核提示。词表变化导致建议不能应用时，新建任务使用新词表；重新生成仍使用旧任务快照。

## 状态、限流与检索

任务 RUNNING/PAUSED/COMPLETED/CANCELLED。歌曲条目 PENDING/PROCESSING/REVIEW/APPLIED/UNCHANGED/FAILED/CANCELLED 互斥；总数为各分类之和，已完成处理为总数减等待和处理中。待审核不是已写入，部分维度已自动应用但仍有建议时计入待审核，详情和历史显示实际结果。

分类使用独立串行调度器、2～300 秒批量请求间隔；429 至少冷却 60 秒并持久化，重试不绕过冷却。暂停不再领取新条目，进行中的请求可保存为待审核但不自动应用；终止保留已应用和审核结果，剩余条目标终止。重启将处理中放回等待、运行任务暂停，管理员确认继续。保存设置暂停运行任务；原任务继续使用原快照，关闭分类功能后不能继续。配置测试为显式单次请求，不加入批量队列。

`/api/v1/classification` 提供配置/测试、词表、歌曲状态/人工写入/历史/撤回、输入预览、分页任务和明细、暂停继续终止、单项重试/审核接口。完整字段见 OpenAPI。歌曲列表 `tagIds` 同维度 OR、跨维度 AND；`unclassified=true` 查无启用标签的歌曲。词表数量与列表均仅计现存歌曲，停用标签不参与正式筛选。标签关系双向索引；继续使用延迟关联分页，不在前端过滤当前页冒充分页检索。

SQLite/MySQL 的同名 dbmate 初始化迁移 `202611070001_initial_schema.sql` 直接定义分类配置、标签、任务及审核结果表，业务 SQL 全部在 模块内嵌 SQL。未接入真实模型时只能证明流程与协议验证通过，不能宣称分类准确率。


新任务冻结当前绑定模型及其协议、输出模式、凭据用途和请求间隔。变更绑定或被绑定模型会暂停活动分类任务，不改写任务快照。旧快照缺少新字段时继续按原 Chat Completions / JSON Schema 协议及旧凭据用途读取。旧 `/api/v1/classification/settings` 仍可读取和保存，写入通过适配更新共享服务和分类绑定；新界面不再用旧入口编辑配置。
