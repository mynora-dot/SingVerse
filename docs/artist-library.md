# 自动歌手库

管理入口：「曲库管理 → 歌手库」。扫描歌曲后自动生成，不需要新建人物、维护资料或手动关联。

## 数据与订正

歌手来自当前歌曲的有效歌手字段：人工 NAS 订正优先于内嵌标签，其次为已确认平台信息和文件名解析。对名称去除首尾空白、统一 NFKC 后汇总，沿用既有多人署名解析；不猜测拆分、艺名或中英文别名。同名默认一个浏览入口，同歌重复署名只计一次。

点击歌手查看歌曲，点击「订正歌曲」使用现有编辑/确认应用流程。仅手动编辑并确认歌手字段时生成 NAS 覆盖值；平台候选不能覆盖已有人工订正。覆盖值按来源和相对路径保存，重新扫描或文件大小/时间变化后仍保留，不写入原件。点击「恢复歌手」并确认后恢复扫描信息，使用版本避免旧请求覆盖新修改。其他元数据字段沿用既有内嵌标签优先规则。

歌手库可在分页前按“歌曲数量小于指定值”和男歌手、女歌手、乐队/组合筛选，条件可与名称搜索叠加。歌手类型由管理员在详情中标注；系统不凭名字或照片推断性别。已有 `PERSON` 和未标注记录归入“未分类”。列表卡片缩小了背景图和信息区，分页紧跟卡片列表。

扫描、应用元数据、订正、恢复和移除来源提交后使共享索引失效，下次读取立即重建。无歌曲的歌手隐藏但保留图片缓存，再次入库复用。改名不转移旧名称图片。新歌手记录在索引构建中建立，后台启动后也会自动扫描已有曲库并补齐。

## 首次自动图片

一个独立串行 Go 后台工作器从持久化状态读取任务；网络请求不在扫描或业务事务中执行，不阻塞入库。网易云优先，QQ 音乐备用，复用现有 HTTP、加密与平台限流；无需额外服务、账号或必填密钥，并尊重已有平台启用列表。

优先使用已确认平台歌手 ID；否则核对名称及最多三首歌曲。只有名称、至少一首歌名匹配且平台歌手 ID 唯一才应用；同名歧义或无法确认时保留占位，不建立人工审核流程。平台返回的歌手头像单独读取，不用专辑封面代替。当前接入源仅提供头像，没有可靠独立背景图时保留中性背景，背景可上传。

平台请求全局串行且至少间隔 1.5 秒。临时错误在 10 分钟、1 小时、6 小时后最多重试三次，无匹配停止自动搜索；重启保留状态。「重新获取图片」重置失败状态。人工上传永远优先，抓图期间上传也不会被覆盖；移除图片会暂停该用途自动补图，重新获取才解除暂停，已有上传图仍保留。

头像和背景图现在分别记录任务状态；已有头像不妨碍背景补图。原网易云/QQ 头像来源保留，缺图时增加 TheAudioDB 官方接口。TheAudioDB 只有在歌手具有 MusicBrainz ID、且至少一首关联歌曲能在 MusicBrainz 录音中核对时才自动应用；中文署名可经 MusicBrainz 别名核对。未核实或多位候选不自动取第一张，管理端显示候选供确认。配置 Fanart.tv 个人 API 密钥后，可信 MusicBrainz ID 可补充背景图；密钥在管理员「图片来源设置」中加密保存，接口只返回配置状态。设置新密钥会重试尚无背景的歌手。

图片详情展示来源与原图链接。TheAudioDB 图片按其使用条款展示来源；Fanart.tv 图片通过其官方 API 获取。第三方覆盖率、许可与可用性随数据源变化；外部请求按来源限流，429/超时按临时故障重试。管理员可对缺图用途使用「重新获取图片」。

图片仅通过受限 HTTPS 平台/CDN 请求读取，禁用重定向、拒绝私网目标并限制超时/体积。下载或上传图片最长边最多 4096、大小最多 2,000,000 字节，实际解码验证 JPEG/PNG，最长边缩至 1280 后存为 JPEG。网易云 `image/jpg` 按 JPEG 校验，上传仍要求 JPEG/PNG。图片带来源、平台 ID、URL 和内容版本，客户端只读取 NAS 鉴权图片接口。

## 数据与接口

SQLite/MySQL 的 `202611070001_initial_schema.sql` 直接定义名称标识、歌手覆盖值、图片来源、暂停策略及头像/背景独立抓图状态，业务 SQL 均在 模块内嵌 SQL。空库歌手由扫描后的有效署名生成，上传图片与 NAS 歌手覆盖按当前业务规则保存。

原 `/api/v1/artists` 与 TV 歌手查询读取自动汇总结果；管理员 `/{id}/songs` 返回现有完整歌曲模型用于编辑。旧新建/编辑档案、绑定写接口返回 410 并提示订正歌曲。新增 `POST /api/v1/artists/{id}/images/retry`、`GET/DELETE /api/v1/artists/song-overrides/{songId}`，恢复需 revision。图片上传/读取沿用已有接口。完整契约见 OpenAPI。
管理员列表新增 `type` 和 `countLessThan` 查询参数，类型标注使用 `PUT /api/v1/artists/{id}/category` 并校验 revision。类型只影响筛选与显示，不改变歌曲归属或图片。

管理员 Cookie/CSRF 与 TV/亲友权限隔离不变。不引入 Redis、消息队列、Python 任务或转码。外部接口可能失败，不承诺所有歌手都有图片；无图时仍可浏览和点歌。
